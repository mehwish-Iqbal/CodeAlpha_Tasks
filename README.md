# CodeAlpha_Tasks

This repository contains my projects completed during my **CodeAlpha Data Analytics Internship**.

The projects focus on **Exploratory Data Analysis (EDA), Data Visualization, and Sentiment Analysis** using Python and real-world datasets.

---

## 🗂️ Dataset Overview

The projects use real-world datasets, including the **Olist Brazilian E-Commerce Dataset** and **Amazon Customer Reviews Dataset**.

For the Olist e-commerce analysis, the relevant datasets were merged to create a consolidated `sales_data` containing:

**112,650 rows × 16 columns**

The Sentiment Analysis project uses Amazon customer reviews to analyze customer opinions and emotional patterns:

**21,214  Rows ×  9 colunms**

### 🔹 Task 3 — Sentiment Analysis & Emotion Detection

**Dataset:** Amazon Customer Reviews Dataset

In this task, I analyzed customer reviews to classify them into **Positive, Negative, and Neutral** sentiments and identify specific emotional patterns expressed in the reviews.

**Key Areas Covered:**

* Text data cleaning and preprocessing
* Sentiment classification using **VADER**
* Positive, Negative, and Neutral sentiment analysis
* Emotion detection using a **keyword-based emotion lexicon**
* Sentiment analysis by customer rating
* Sentiment analysis by country
* Monthly sentiment trends
* Business-focused customer insights

### 📊 Sentiment Results

| Sentiment | Reviews | Percentage |
| --------- | ------: | ---------: |

| Negative  |   9,394 |     44.62% |
