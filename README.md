# CodeAlpha_Tasks

This repository contains my projects completed during my **CodeAlpha Data Analytics Internship**.

The projects focus on **Exploratory Data Analysis (EDA)** and **Data Visualization** using Python and real-world e-commerce data.

---
## 🗂️ Dataset Overview

The **Olist Brazilian E-Commerce Dataset** contains information about orders, order_items ,products, customers, payments, and sales transactions.

After merging the relevant datasets, the consolidated `sales_data` contains:

**112,650 rows × 16 columns*

----


## 📂 Projects

### 🔹 Task 1 — Exploratory Data Analysis (EDA)

**Dataset:** Olist Brazilian E-Commerce Dataset

In this task, I explored the structure, quality, relationships, and key business patterns within the e-commerce data.

**Key Areas Covered:**

* Dataset structure and data types
* Missing value analysis
* Duplicate records check
* Categorical variable analysis
* Data quality checks and handling
* Dataset merging and relationships
* Revenue and sales analysis
* Customer and order analysis
* Delivery performance
* Payment analysis
* Chi-Square statistical testing
* Key business insights

**Tools:** 
* Python
* Pandas
* NumPy 
* Jupyter Notebook

📁 **Folder:** `Task_01_ Exploratory Data analysis(EDA)`

### 🔹 Task 2 — Data Visualization

**Dataset:** Olist Brazilian E-Commerce Dataset

In this task, I created visualizations to identify sales trends, customer patterns, payment preferences, and delivery performance.

**Visualizations Created:**

1. 📈 **Monthly Sales Revenue Trend**
2. 📊 **Top 10 Product Categories by Revenue**
3. 📊 **Top 10 States by Number of Customers**
4. 🥧 **Payment Method Distribution**
5. 📊 **Orders by Day of the Week**
6. 📈 **Revenue by Day of the Week**
7. 🔵 **Product Price vs Freight Value**
8. 📊 **Top 10 Product Categories by Average Delivery Difference**

These visualizations helped transform the e-commerce data into **clear and business-focused insights**.

**Tools & Libraries:** 
* Python
* Pandas
* Matplotlib
* Seaborn
* Plotly
* Jupyter Notebook

📁 **Folder:** `Task_02_ Data Visualization`
